# Roadmap

The goal is to cover the common icon concepts people need (the same list of ideas as the free "Classic" set of Font Awesome, without brand logos). **Only the concept and the name are taken from that list: every icon is drawn from scratch** in the fontfine style (see [AGENTS.md](AGENTS.md)). Final names may differ; when they do, the fontfine name is shown in parentheses.

Each icon needs line, solid and duotone versions plus metadata. Work goes in reviewed batches of about 100.

**Progress: 121 / 1422**

Want to help? Pick unchecked icons, follow [CONTRIBUTING.md](CONTRIBUTING.md) and open a pull request.
