Documentation

fontfine is a free, open source set of {{ total }} icons. Every icon has 6 variants, its own animation and a stroke width you can change. It works with React, Angular, Vue, plain HTML and any server.

Install

React

Each icon is a component named in PascalCase (arrow-left → ArrowLeft). Your bundle only includes the icons you import.

Any other SVG prop (className, style, onClick, ref…) is passed to the <svg>.

Angular, Vue, Svelte or plain HTML

Import the web component once. It registers <fontfine-icon>. Its default size is 1em, so it follows the font size.

Angular

Add CUSTOM_ELEMENTS_SCHEMA to the component.

Vue

SVG string

For any framework, server rendering, emails or Node scripts. Icons are exported in camelCase (arrowLeft).

Raw SVG files

The package also ships the plain files. You can also copy or download any icon from the Icons page.

Variants and stroke

@for (v of versiones; track v.id) { }

strokeWidth only affects line variants. Icons use currentColor, so they take the text color unless you pass color.

Duotone colors

Duotone icons have two layers: .ff-primary (solid) and .ff-secondary (40% opacity). By default both use the icon color.

@for (n of ['bell', 'home', 'calendar', 'camera']; track n) { }

Animations

Every icon has its own animation: the bell swings, the heart beats, the gear spins. Hover the icons:

@for (i of animados; track i.nombre) { }

React

Web component

Animations turn off automatically for people who enable "reduce motion" in their system.

Accessibility

Without a title the icon is decorative and hidden from screen readers. Give it a title when it is the only content of a button or link.

Contributing

New icons are welcome, drawn by hand or with AI. Every pull request is checked automatically and reviewed before it is merged.
